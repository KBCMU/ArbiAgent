<objective>
Stop Polymarket from emitting multiple CandidateEvents for the same (slug, market_type_bucket) within a single process_gamma_events call. The double-emit occurs because the moneyline emit path and the spread/total emit path both fire for the same event slug when a grouped market has a Strategy-3 moneyline fallback.

Purpose: Duplicate CandidateEvents with the same slug cause the same game to appear as two separate entries in the event table.
Output: fetcher_polymarket.rs with a seen HashSet guard in process_gamma_events, verified by 2 new tests.
</objective>

    let mut candidates = Vec::new();
    for event in events {
        // ... filtering, classification ...
        let slug = ...; // String
        let (token_ids, mut outcome_labels, is_moneyline) = extract_moneyline_market(&event);
        // ...
        // Moneyline emit path (line ~242):
        if !token_ids.is_empty() {
            // ... label normalization ...
            if !outcome_labels.is_empty() {
                let market_type = if is_moneyline { MarketType::Moneyline } else { MarketType::Moneyline };
                candidates.push(CandidateEvent { ..., market_type, polymarket_slug: Some(slug.clone()), ... });
            }
        }
        // Spread/total emit path (line ~262):
        let extra = extract_spread_total_markets(&event, sport);
        for (market_type, tids, labels) in extra {

        }
    }
    candidates
}
