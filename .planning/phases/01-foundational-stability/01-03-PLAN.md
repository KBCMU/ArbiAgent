Output: cache.rs with never-downgrade merge logic and token_ids_differ helper; mod.rs with token_ids_differ imported and used for the token_ids_changed check; 3 new tests in cache.rs; 1 updated comparison in mod.rs.

    ```rust
    /// Compare two polymarket token ID sets in an order-independent way.
    /// Returns true if the sets differ (different elements, regardless of order).
    fn token_ids_differ(a: &[String], b: &[String]) -> bool {
        if a.len() != b.len() { return true; }
        let mut sorted_a = a.to_vec();
        sorted_a.sort();
        let mut sorted_b = b.to_vec();
        sorted_b.sort();
        sorted_a != sorted_b
    }

    /// Insert or update a canonical event with merge semantics.
    ///
    /// Never-downgrade rule (D-04): if the cached event has both platforms' data
    /// and the incoming event has only one platform, keep the cached version.
    ///
    /// Token change detection (D-05): if polymarket_token_ids changed, clear
    /// stale Polymarket odds to prevent dead-token prices from being used.
    pub fn upsert_event(&self, event: CanonicalEvent) {
        let incoming_is_dual = event.platform_ids.kalshi_event_ticker.is_some()
            && event.platform_ids.polymarket_market_slug.is_some();

        if let Some(cached) = self.events.get(&event.id) {
            let cached_is_dual = cached.platform_ids.kalshi_event_ticker.is_some()
                && cached.platform_ids.polymarket_market_slug.is_some();

            // D-04: never downgrade dual-platform to single-platform.
            if cached_is_dual && !incoming_is_dual {
                debug!(
                    "upsert_event: refusing downgrade for {} (cached=dual, incoming=single)",
                    event.id
                );
                return;
            }

            // D-05: if token IDs changed, clear stale Polymarket odds.
            if token_ids_differ(
                &cached.platform_ids.polymarket_token_ids,
                &event.platform_ids.polymarket_token_ids,
            ) {
                debug!(
                    "upsert_event: token IDs changed for {} — clearing stale Polymarket odds",
                    event.id
                );
                drop(cached); // release the DashMap read guard before the mutable call
                self.clear_platform_odds(&event.id, "polymarket");
            }
        }

        self.events.insert(event.id.clone(), event);
    }
    ```

    Important: `token_ids_differ` must be a free function (not a method) inside the `impl StateCache` block or as a standalone function in the same file — either works. Place it ABOVE upsert_event for clarity.

    DashMap guard release: in DashMap 6.x, the guard from `self.events.get()` must be dropped before calling `self.events.insert()` to avoid a deadlock. The `drop(cached)` call above handles this. Verify by running the tests — if there is a deadlock, it will hang; add `drop(cached)` before both the return AND the insert.
